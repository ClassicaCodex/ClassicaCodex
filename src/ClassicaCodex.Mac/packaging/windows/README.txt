Classica Codex for Windows (preview)

Run "Classica Codex.exe" in this folder. Nothing needs installing: the app
carries its own copy of .NET, and the folder can live anywhere you can write
to, such as your Documents. To remove it, delete the folder.

Windows may show a blue SmartScreen box the first time, because the download
isn't code-signed. Choose More info, then Run anyway.

BESIDE THE CLASSIC WINDOWS APP

This is a new interface for the same app. It doesn't replace the classic
Windows app, and the two can sit side by side.

It keeps its settings in %LOCALAPPDATA%\ClassicaCodex, the classic app's own
folder. So if you already use that app, this one opens on your library at the
passage you left, with your AI keys, text size and download folder. Anything
you change in those is changed in both. Nothing is copied, so there is nothing
to migrate, and the library stays one file.

Close one app before setting up or updating a library in the other, as you
would with two copies of any program on one file.

THE ICON AND THE START MENU

There is no installer, so nothing is added to the Start menu. To keep the app
to hand, right-click "Classica Codex.exe" and choose Pin to Start, or Show more
options, then Pin to taskbar.

WHAT IS OPTIONAL

    Read Aloud        Windows' own voices, from Settings > Time & Language > Speech.
    Ancient scripts   Segoe UI Historic, which ships with Windows, draws
                      cuneiform and Egyptian hieroglyphs. Noto Sans Cuneiform
                      and Noto Sans Egyptian Hieroglyphs are used instead if
                      they are installed.
