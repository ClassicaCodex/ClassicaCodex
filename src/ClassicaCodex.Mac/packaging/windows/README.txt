Classica Codex for Windows

Run "Classica Codex.exe" in this folder. Nothing needs installing: the app
carries its own copy of .NET, and the folder can live anywhere you can write
to, such as your Documents. To remove it, delete the folder.

Windows may show a blue SmartScreen box the first time, because the download
isn't code-signed. Choose More info, then Run anyway.

COMING FROM THE CLASSIC WINDOWS APP

From 3.17.0 this is the Windows download, in place of the classic app
(ClassicaCodex.UI.exe). It is the app the Mac and Linux run, with the same
tools, laid out differently: a sidebar holds the library and every tool where
the classic app had eighteen toolbar buttons, and All Tools (Ctrl+Shift+T)
shows them all at once.

It keeps its settings in %LOCALAPPDATA%\ClassicaCodex, the classic app's own
folder. So it opens on your library at the passage you left, with your AI
keys, text sizes, download folder, and the light or dark you chose there.
Nothing is copied, so there is nothing to migrate, and the library stays one
file.

The classic app still works if you keep its folder, and the two can sit side
by side. Close one before setting up or updating a library in the other, as
you would with two copies of any program on one file.

EVERYDAY KEYS

    F1                       Help
    Alt+Left, Alt+Right      Back and Forward
    Ctrl+F                   Search
    Ctrl+L                   Filter the library
    Ctrl+Shift+K             Concordance
    Ctrl+Shift+B             Bookmarks
    Ctrl+E                   Export the selected passage
    Ctrl+Shift+C             Copy the selected passage
    Ctrl+Plus, Ctrl+Minus    Bigger and smaller text (Ctrl+0 for the default)
    Ctrl+Alt+S               Hide or show the sidebar
    Ctrl+Shift+T             All Tools
    Ctrl+,                   Settings

THE ICON AND THE START MENU

There is no installer, so nothing is added to the Start menu. To keep the app
to hand, right-click "Classica Codex.exe" and choose Pin to Start, or Show more
options, then Pin to taskbar.

WHAT IS OPTIONAL

    Read Aloud        Windows' own voices, from Settings > Time & Language > Speech.
    Ancient scripts   Segoe UI Historic, which ships with Windows, draws
                      cuneiform and Egyptian hieroglyphs. Noto Sans Cuneiform
                      and Noto Sans Egyptian Hieroglyphs are used instead if
                      they are installed.
