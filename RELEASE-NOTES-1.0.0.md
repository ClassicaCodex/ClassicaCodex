## ClassicaCodex v1.0.0

Initial public release of ClassicaCodex, an offline browser and research
environment for classical Greek and Latin texts.

### Features

- Browse Perseus Greek and Latin corpora
- Side-by-side original text and translations
- Full-text search and concordance tools
- Lemma and word-study tools
- Passage tags, bookmarks, and exports
- Myth relationship graph
- Places map and timeline
- Local SQLite database
- Automatic corpus setup

### Installation

1. Download `ClassicaCodex-v1.0.0-win-x64.zip`.
2. Extract the entire ZIP.
3. Run `ClassicaCodex.UI.exe`.
4. Follow the setup prompts.

### Platform

- Windows 64-bit
- No separate .NET installation required
